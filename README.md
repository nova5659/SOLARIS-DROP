# SOLARIS DROP // SKYWARD PROTOCOL

밝은 천공 도시(Daylight Sky-Citadel) 테마와 라이트 글래스 UI/HUD로 재창작한 3D 1인칭 하이퍼 모빌리티 아레나 슈터입니다.

## 주요 특징
- **밝은 주간 3D 월드:** 6개 캠페인 섹터 + 전술 훈련장 전체의 스카이돔, 프로시저럴 PBR 텍스처, 조명 및 무기 도색을 밝은 주간 분위기로 재구성
- **새로운 라이트 글래스 UI & HUD:** 상단 플로팅 내비게이션, 하단 미션 도크, 겹침 없는 투명 글래스 전투 HUD 및 주간 미니맵
- **풍부한 게임플레이:** 10웨이브 캠페인 · 무한 강하 · 오늘의 작전 · 7종 무기 · 4종 파일럿 기체 · 24종 전술 카드 & 시너지 · 8종 영구 강화 · Web Audio 프로시저럴 사운드

## 로컬 실행
```bash
node server.js
```
브라우저에서 `http://127.0.0.1:3456` 접속.
